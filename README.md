💰 CashLog

CashLog is a personal finance web app designed to help you track and manage your money efficiently. Built with HTML, CSS and JavaScript, it lets you record transactions, set budgets, monitor saving goals, and even split bills with friends — all presented through a sleek dashboard with interactive charts and visual insights.


🚀 Features

 📊 Dashboard Overview
- Displays your income, expenses, and savings at a glance.  
- Includes pie charts and bar graphs for clear visual tracking.  
- Real-time updates whenever you add or edit transactions.

💸 Add Transactions
- Quickly log your income or expense with category, amount, and date.  
- Automatically updates totals and graphs.

🎯 Budgets
- Set monthly or custom budgets.  
- Get visual feedback when nearing or exceeding your limits.

💰 Saving Goals
- Create financial goals (e.g., “New Laptop Fund”).  
- Add savings progress over time and track it visually with dates.

🤝 Split Bills
- Split any expense equally or unequally between friends — like Splitwise!  
- Keeps a record of who owes whom and how much.

---

🛠️ Tech Stack

- HTML5 – Structure and UI components  
- CSS3 – Styling and responsive layout  
- JavaScript (ES6) – Logic, interactivity, and chart integration

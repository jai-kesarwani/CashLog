# 💸 CashLog

CashLog is a modern full-stack personal finance management web application that helps users track income, expenses, and split bills efficiently with a clean and responsive UI.

Built using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB Atlas.

---

# 🚀 Features

## 📊 Dashboard

* View total balance
* Track total income and expenses
* Recent transaction overview
* Dynamic dashboard updates

## 💰 Transactions

* Add income and expense entries
* Edit existing transactions
* Delete transactions
* Filter by type, category, and month
* Real-time MongoDB updates

## 🤝 Split Bills

* Create split bills with friends
* Equal and unequal splitting support
* Mark participants as paid
* Mark entire bill as settled
* Dynamic payment status updates
* Splitwise-style UI

## 👤 Account Section

* Profile card
* Edit profile functionality
* Country selection
* Currency settings
* Change password section
* Real-time sidebar profile sync

## 🌙 UI Features

* Responsive modern UI
* Dark/light mode support
* Clean SaaS-style design
* Smooth modal interactions

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/cashlog.git
cd cashlog
```

---

## 2️⃣ Install Backend Dependencies

```bash
cd backend
npm install
```

---

## 3️⃣ Create `.env` File

Inside `backend/` create:

```env
MONGO_URI=your_mongodb_connection_string
PORT=5000
```

---

## 4️⃣ Run Backend Server

```bash
npm start
```

Server runs on:

```bash
http://localhost:5000
```

---

## 5️⃣ Run Frontend

Open:

```bash
index.html
```

OR use Live Server extension in VS Code/Windsurf.
